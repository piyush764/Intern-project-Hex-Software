A minimal, fast, and beautifully styled task manager built with Vanilla HTML, CSS, and JavaScript.

Features :-
Add, complete, and delete tasks
Persistent storage using Local Storage (tasks stay after refresh)
Live stats (Total / Pending / Done)
Progress bar based on completion
Filters: All / Active / Completed
Clear completed tasks
Timestamps for each task
Keyboard support (Enter to add)
Smooth animations and micro-interactions
Fully responsive layout
Clean, modern UI design

🛠️ Tech Stack
HTML — Structure
CSS — Styling, layout, animations
JavaScript (Vanilla) — Logic, state management, storage

No frameworks or dependencies.
